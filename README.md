# Fishing-app

Autonomous product discovery and prototyping for a paid web app in recreational fishing, on
Supabase + Netlify, buildable by a solo founder.

Start with `docs/progress.md` (where things stand), `docs/decision-log.md` (why), and
`docs/approvals.md` (anything that needs the founder).

```
research/        market sizing, hobby immersion, competitors, monetization, gap analysis, red team
docs/            progress, decisions, sources, approvals, validation gate, skills log, scaling, adr/
deliverables/    prototype.html, report.md, report.html
prototype/       working files for the prototype
app/             production starter (React + Vite + TypeScript + Tailwind, Supabase, Netlify)
.claude/skills/  reusable skills created during the project
```
